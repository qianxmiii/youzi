# 运单文件重命名

> **落地状态（2026-08-12）**：已落地——工具中心 `/tools/shipment-file-rename`；Excel 由后端解析，本地文件夹在 Chrome/Edge 用 File System Access API 重命名。

## 目标

将文件夹内以运单号命名的文件（如 `DPSECO260812093.pdf`），按导入 Excel 中的国家、仓库代码、件数，批量改为：

```text
{运单号}-{国家}-{仓库代码}-{件数}.pdf
```

示例：`DPSECO260812093-CA-3PL-18.pdf`

## 输入

Excel 表头需包含（别名亦可）：

| 字段 | 常用表头 | 必填 |
| --- | --- | --- |
| 运单号 | 运单号 | 是 |
| 国家 | 国家 | 是 |
| 仓库代码 | 仓库代码 / 派送仓库 | 是 |
| 件数 | 件数 | 是 |
| 文件夹名 | 文件夹名 / 目录名 | 否；有值时相同名归入同一子目录 |

文件夹内文件名（去扩展名）须与运单号一致。

有「文件夹名」时目标路径示例：

```text
A组/DPSECO260812093-CA-3PL-18.pdf
A组/DPSECO260812094-US-AVP1-10.pdf
B组/DPSECO260812095-US-LAX9-5.pdf
```

## 流程

1. 上传 Excel → `POST /api/v1/tools/shipment-file-rename/parse`
2. 浏览器选择本地文件夹（需读写授权）
3. 预览匹配结果（将重命名 / 已是目标名 / 冲突 / Excel 无此单）
4. 确认后在本地重命名；PDF 不上传服务器

## 边界

- 仅 Chrome / Edge 等支持 `showDirectoryPicker` 的浏览器
- 支持 `.xls` / `.xlsx`；多工作表时自动扫描各 Sheet（优先「运单信息」）查找表头
- 表头可含换行或括号说明（如 `件数\n（箱）`）
- 同名单冲突或目标文件名已存在时跳过
- Excel 有单、文件夹无对应文件时，在摘要中提示「文件夹缺 N 单」
- 不修改业务库数据
