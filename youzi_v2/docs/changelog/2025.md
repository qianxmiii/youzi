# 2025 年历史更新

返回[主更新记录](../../CHANGELOG.md)。本页日期沿用原记录，未根据当前代码推断或改写年份；历史行为不代表当前规则。

## 2025-06-04

### 新增

- 建立架构、数据库、部署、API、运单和仓库业务文档，以及模块 README 和文档同步约束。
- 增加运单轨迹订阅、未读消息与通知操作；工作台提供预警、提醒与关注运单入口。

### 优化

- 重整运单轨迹抽屉、列表操作、船期监控与侧栏导航分组。
- 统一字体、图标、状态标识和明暗主题，改善多时区及时间信息展示。

### 修复

- 修复轨迹抽屉承运商字段误用和 Windows 世界时间保存失败的问题。

### 升级说明

- Windows 时区支持增加 `tzdata` 依赖，部署时按依赖清单安装。
