# 更新记录

记录功能变化、重要修复和升级事项，按日期倒序排列。主文件保留最近三个自然月（当前为 2026 年 8—10 月）。

历史归档：[2026 年 7 月及以前](./docs/changelog/2026.md) · [2025 年](./docs/changelog/2025.md)。写法见[更新记录规范](./docs/changelog-policy.md)；接口和配置细节见[文档中心](./docs/README.md)。历史条目描述当时的变化，使用现状以当前功能文档为准。

## 2026-10-23

### 优化

- **下单助手**：允许操作的页面地址改为本机配置，不再写入代码。

## 2026-10-22

### 新增

- **补货件号推送亚马逊**：保存货件号后按港口规则调用 `dps_update_amz`（预约号可空，空则传 `""`）。窗口里的起运港、目的港带默认值且可改，推送使用改后的值。同一票 60 秒内不可再推，失败同样冷却。对方 HTTP 成功但业务 `code` 不是 `200` 或 `0` 时，页面提示返回的 `msg`。需在 `config.json` 配置 `dps_update_amz.url`。规则见 [dps-update-amz-design.md](./docs/design/dps-update-amz-design.md)。
- **港前更新全部运单**：港前列表可一次按运单号从 DPS 更新已下单、提货中、已入仓，不含已取消。写入方式与「更新选中运单」相同。
- **FBA 箱号展开**：生成结果可导出 Excel，一列箱号，与页面列表一致。
- **亚马逊异常**：港后新增异常类型，编码 `AMAZON_EXCEPTION`，英文 Amazon exception。启动时写入运单异常码表，不覆盖已有记录。

### 优化

- **复制运单明细**：港前与在途多票复制时，运单之间不再空一行。

## 2026-10-21

### 新增

- 运单支持按供应商精确筛选；在途运单支持筛选并补录缺失的货件号、预约号。
- 唛头下载支持自定义字段顺序、分隔符、文件夹和国家语言；派送仓库为空时回退邮编。

### 优化

- 运单列表移除分组列，保留分组操作和筛选。
- 更新渠道报价配置；收到新价卡后同步更新查价页日期。

### 修复

- 修复部分 Windows 环境无法生成进仓单 PDF、新建运单未出现在港前列表的问题。
- 修复下载进度弹窗文字不清晰、货件号和预约号显示重叠的问题。

### 升级说明

- 启动时将空状态及 `UNKNOWN` 迁移为“已下单”（`0`）；新建运单默认状态同步调整。

## 2026-10-20

### 优化

- 核对并更新渠道报价配置和查价页日期。

## 2026-10-19

### 优化

- 近期到港按往前三天、今天、往后三天分组，包含 ETA 已过但尚未实际到港的批次。
- 统一运单与催款列表的转运中状态标识。

## 2026-10-18

### 新增

- 运单分为港前、在途两个工作台；港前支持提货中、已入仓的独立定时及手动同步。
- 异常支持港前、港后分类；客户管理支持按当前筛选导出 Excel。
- 运单支持计费重展示与复制，以及进仓单、进仓单 PDF、单票唛头按件数拆分下载。
- 今日动态增加到中转仓、快递交仓、轨迹签收节点，并支持跳转到对应运单筛选。

### 优化

- 重整工作台首页的明细状态、干线进程、今日动态与近期到港展示。
- 在途列表默认筛选转运中；港前隐藏不适用的轨迹、付款字段和操作。
- 收货仓统一命名并支持筛选；保留旧 Excel 表头兼容。货箱下载统一命名，多票按文件夹打包。
- 运单下载增加进度反馈；异常跟踪优化历史筛选、跟进操作和表格固定列。

### 修复

- 修复港前同步时间范围、粗状态误判、状态中文显示和内部轨迹摘要被明细同步覆盖的问题。
- 进仓单 PDF 改为由同一模板 Excel 转换，保持与 Excel 下载版式一致。

### 升级说明

- 启动时将旧状态 `IN_TRANSIT`、`DELIVERED` 迁移为 `2`、`3`；已有异常类型默认归为港后。
- Windows 生成进仓单 PDF 需 Microsoft Excel 与 `pywin32`，也可使用 LibreOffice；详见[部署说明](./docs/deployment.md)。
- 移除唛头 Word 下载及相关 API，移除 `pdf2docx`、`python-docx` 依赖；PDF 下载和拆分继续可用。

- 承运商轨迹支持备用来源；运输时效排除异常持续超过七天的运单。
