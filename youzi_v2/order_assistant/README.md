# DPS 下单填表助手（0.4.1：只填显示且有值的字段）

0.4.1 修复：勾选客户单号与 Shipment ID 一致但缺少 Shipment ID 时，保留已提供的客户单号；批量填写遵循“允许替换本次启用字段的已有值”勾选状态。地址选项、控件或简称映射出错只影响该字段，其余已启用且有值的字段继续填写。

## 本次填写规则

以用户勾选的“显示字段”为本次填写范围：

- 显示且有值：填写并核对。
- 显示但空白：跳过，不补造值、不清空网页。
- 隐藏：不填写、不切换、不套默认值；即使表格、模板里有值，也不发送到填写脚本。
- 没有助手强制必填项。某字段无值、格式错误、找不到控件或选项时，分别报告，继续处理其他启用字段。

折叠整个公共设置面板不改变勾选范围；需要排除某个字段时，取消该字段的“显示”勾选。显示偏好保存在当前浏览器。更新显示范围会清除旧摘要，并重新计算当前范围的数据问题。

保险、DPS 清关等控件已有的“否”是界面上的值：只有勾选显示才填写，手工清空后跳过。派送联系人不会在后台凭空补成“待定(000000)”；需要此值时，让该字段显示并填上这个完整选项名。助手不直接写入隐藏字段，DPS 自身的联系人、国家、地址等联动仍由网页处理。

## 日常流程

1. 从已登录的 DPS 新建运单页打开助手，按需打开独立工作台。
2. 在“公共模板与补充字段 → 设置显示字段”勾选本次要填写的项目，可“仅显示常用”或“显示全部”。
3. 导入 CSV/TSV 或粘贴 Excel 表格；也可直接在显示的公共字段中输入。只要列名能识别，不要求保留全部模板列；单元格可留空。
4. 点击“填写本条”。同一单可补填；已有相同值会保留，已有不同值按替换设置及防错规则处理。切换另一队列行时，上一单内容未清理则停止，避免混单。
5. 查看整单核对摘要。修改网页后可“重新核对网页”，只读取本次启用的字段，不改表单。明细可展开或收起。
6. 核对完整页面后，可点击“录入完成，点击下单”。助手只检查本次启用且有目标值的项目，不增加隐藏项或空白项的必填要求；其他校验由 DPS 网页负责。
7. 本人查看 DPS 成功提示或运单记录，确认真正成功后再勾选并记录下一条。“已点击”不等于“已成功”。

填写、核对、定位与单项重试不会点击下单。只有明确点击下单入口才会触发唯一可见、可用的“下单”按钮一次，不自动点后续弹窗，不连续批量提交。

## 表格、模板与编号

每批最多 500 行、2 MB。支持 UTF-8、GBK/GB18030、带 BOM 的 UTF-16；不直接读取 .xlsx，可另存 CSV 或复制粘贴。编号按文本保留前导零，不使用科学计数法；数量不要带单位。无法识别或重复的表头、损坏引号和列数错误需先修正。

完整模板为 24 列，旧版 10 / 13 / 15 列继续兼容，也可只保留本次需要的已知列：

```text
销售,客户,公司名称,渠道名称,客户单号,关联单号,报关类型,交货仓库,派送地址,Shipment ID,Reference ID,箱数(CTN),毛重(KG),体积(CBM),产品品名,派送地址类型,派送联系人,派送公司名称,派送手机号,派送国家,派送省份,派送城市,派送地址邮编,派送详细地址
```

“客户”也接受“大客户”，不可同时出现。报关类型支持“买单”“退税”“买单+退税”。箱数、毛重、体积只写入派送信息，不写产品说明中的同名控件。产品品名有值时写入对应文本框；遇到同名控件无法唯一识别时报告，不猜测。

显示字段有公共输入、订单行也有非空值时，订单行优先。客户单号启用后，可勾选“与 Shipment ID 一致”，按当前行源 Shipment ID 生成客户单号并保留前导零；隐藏客户单号则不修改它，源 Shipment ID 缺失时保留已提供的客户单号，两者都为空才跳过。勾选只更新预期值，实际填写仍由按钮触发。确认历史使用本次实际派生的编号组合，不修改原始导入行或源 CSV。

## 两种派送地址

“派送地址类型”也属于可启用字段：隐藏时不切换，显示并选择 FBA 或其它地址时才切换。顶部快捷选择与该公共字段同步，订单行明确提供的类型优先。

- FBA：填写系统完整地址选项名，例如 US-ABE8[08518]。先以仓库代码搜索，再精确点击完整名称一致的唯一选项。邮编只有启用时才纳入本次联动核对。
- 其它地址：可填写派送联系人、公司、手机号、国家、省份、城市、邮编和详细地址。各字段分别勾选，有值才操作。派送联系人是下拉，待定选项名为“待定(000000)”。不点击联系人“编辑”，不新建联系人。

不能确认某下拉真正选中时，报告需核对，不将搜索文字当作成功。重复或缺失的同名选项不猜选。国家、公司名称等按对应区域定位，避免误填到供应商或进口商区域。隐藏的下拉不能通过“单项重试”绕过填写范围。

## 核对与防重复

摘要只比较本次启用字段的目标值与网页实际值。空白项显示“跳过”，不会被算作缺少必填值。数值 12.50 与 12.5 等价，单号按文本比较。摘要是一次读取的快照，改变输入、勾选范围、订单或名称对照后需重新核对。

下单前持久写入尝试记录，并通过 Web Locks 串行处理。存在订单编号时，以编号摘要识别；编号全空时以本次字段快照摘要识别，不要求为此补齐编号。重复点击、重开工作台、消息中断或页面跳转后不会自动再点。网页校验失败或结果不明确时，先确认 DPS 状态，确实失败后可在网页人工修正处理。此机制不替代 DPS 的服务器防重，也不覆盖其他浏览器或手工点击。

## 安装、权限与数据

在 chrome://extensions/ 打开开发者模式，加载文件夹 C:\Git\youzi\youzi_v2\order_assistant\extension。更新后关闭旧助手、刷新扩展；若提示旧脚本，先保留未提交内容，再刷新 DPS 页面。唯一允许执行的页面写在 `extension/allowed-page.local.js`（从 `allowed-page.example.js` 复制，不进 Git）。

不接受其他域名、编辑页面或带附加参数的地址。扩展只声明 activeTab、scripting、storage，不自动登录、不读取密码或 Cookies，不调用隐藏下单接口。模板、队列、显示偏好、位置绑定和确认历史只存本机 chrome.storage.local；摘要实际值不写入报告或日志。测试仅使用合成数据，没有向真实 DPS 提交测试订单。
