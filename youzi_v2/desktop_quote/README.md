# 柚子报价小窗（Windows）

独立桌面报价计算区，可置顶、缩放、粘贴识别货况、选择显示字段。无需打开业务网页或启动后端。

## 使用

- 双击桌面“柚子报价小窗”或 [启动报价小窗.cmd](./启动报价小窗.cmd)。
- 右上角“已置顶／置顶”切换原生置顶；标题栏可拖动、缩放和最小化窗口。
- 默认采用400×460的紧凑窗口，最小可拖至300×220；小字号、紧凑三列卡片，窄于340时改为两列。计算说明默认折叠，点底部汇率行可展开。缩小时可滚动查看，置顶/设置与复制操作保持可达；配合隐藏不用的字段减少遮挡。
- 宽度足够时，“成本、利润、附加费”单独一行，“毛利率、单价RMB、单价USD”单独一行，不受前面地址等字段数量影响；隐藏某项仍按组换行，窄窗口则自动换成两列。
- “字段／汇率”勾选需要显示的字段；“显示报价识别”可隐藏或显示整个识别输入区，自动记住选择。隐藏不清空本次识别文本或已填货况；“全选”“恢复默认”都会重新显示识别区。显隐与置顶状态会记住。
- “字段／汇率”中可修改汇率，默认 `1 USD = 6.7 RMB`，修改后自动记住，不联网抓取汇率。在“单价 RMB/kg”后显示“单价 USD/kg”，也可独立勾选隐藏；旧版已显示人民币单价时，首次更新会补显美元单价，之后尊重手动显隐选择。
- 成本、利润和附加费均按 RMB/kg 填写，任意一项有金额即实时计算人民币单价、美元单价与毛利率，无需先填箱数、重量或体积。未填金额按0处理。
- “地址／仓码”以英文字母开头时，在本地 `addresses_warehouse` 中查询（不区分大小写）。完整仓码唯一匹配且有邮编时自动带出，邮编保留前导零；只输入部分仓码或同码有多个邮编时显示候选，点击选择。邮编字段即使隐藏，地址卡片也会显示匹配邮编。
- 修改或清空地址会清除上一仓库自动带出的邮编；查询期间手动修改的邮编不会被旧请求覆盖。无匹配、未维护邮编或地址库不可用时可手动填写，数字开头的输入不触发仓库检索。
- 粘贴箱数、总重、总体积，点“识别”或按 Ctrl+Enter；也可以“粘贴识别”。识别结果可手动修改。
- “复制报价”按两行英文格式生成：第一行为 `To 仓码,箱数ctns 实重kg 体积cbm`，第二行为 `DDP 运输方式: 美元单价 usd/kg * 计费重kg = 总价usd`。使用本次已填数据，不受字段显隐影响；排除成本、利润、毛利率和客户名称，不自动发送。没有填写的货况项省略，没有计费重时只复制美元单价。
- 复制的美元总价按显示的两位美元单价×计费重计算，保留两位小数，确保乘式一致；第一行展示实重，第二行使用实际计费重（可能包含材积重或渠道最低计费重）。人民币总价仍按原精度计算。
- 点击“毛利率”“单价 RMB/kg”“单价 USD/kg”的结果数字可单独复制，支持Tab聚焦后按Enter/空格。格式为 `50%`、`10RMB/kg`、`1.42usd/kg`（示例）；人民币单价去除多余小数零，美元单价保留两位，复制后显示成功提示。毛利率单项复制不影响整单复制的排除规则。
- 隐藏仅影响显示，已填值仍参与计算。需要取消其影响，应先将对应值改为0。
- “清空本次”清空输入，保留字段偏好与汇率；关闭窗口不保存客户、货况或金额。

## 安装／更新

首次需要 Python、Node.js/npm 与 Microsoft Edge WebView2 Runtime。双击 [安装并启动.cmd](./安装并启动.cmd)，创建独立 `.venv/`、安装运行依赖、构建界面并创建桌面快捷方式。已有同名快捷方式指向其他程序时不覆盖。

以后启动无需联网、npm或后端。本版是本机Python桌面工具，尚不是可直接拷给其他电脑的独立EXE。项目移动位置后需要重新配置快捷方式。

开发命令：

```powershell
npm --prefix youzi_v2/frontend run build:quote-widget
youzi_v2/desktop_quote/.venv/Scripts/python.exe youzi_v2/desktop_quote/launcher.py --check
youzi_v2/desktop_quote/.venv/Scripts/python.exe youzi_v2/desktop_quote/launcher.py
```

界面入口为 `frontend/quote-widget.html`，可用Vite在浏览器预览，但浏览器不能原生置顶，置顶按钮会禁用。独立构建使用 `vite.widget.config.ts`，不改变业务站构建配置。

## 计算边界

- 复用现有货况识别与基础计费模块：总重向上取整数，总体积向上保留两位；尺寸无单位按厘米，重量按总重解释，不自动乘箱数。
- 计费重取实重与材积重较大值；材积重 = `体积 × 1000000 / 6000`，向上取整数kg。
- Sea/Fast sea express每箱最低12kg，Air express每箱最低10kg；计费方取实际体积与总重/363向上保留两位的较大值。
- 按kg核价：人民币单价=成本+单位利润+每公斤附加费；人民币总报价=人民币单价×计费重，综合单价与人民币单价一致。附加费作为额外收取的费用计入毛利，毛利率=(单位利润+每公斤附加费)/人民币单价，向上取整显示；人民币单价为0时显示0%。只有成本时毛利率为0%，只有利润或附加费时为100%。
- 单价与毛利率不依赖货况；没有计费重时总报价显示0。附加费现已由整票金额改为每公斤金额，旧的整票附加费须先除以计费重再填写；更新后重新构建并重启小窗。
- 美元单价=人民币单价/汇率，保留两位小数；修改汇率只影响美元单价，不改变人民币输入或报价。本版没有CBM计价。
- 本版覆盖截图这一段基础核价，不自动查价卡、判偏远或计算提派费、超长费、分泡等；费用需手动折算为每公斤后填入“附加费”。原网页完整报价规则继续由原网页处理。

## 存储与安全

使用 [pywebview原生窗口API](https://pywebview.flowrl.com/api/) 实现置顶。界面仅由绑定 `127.0.0.1` 的临时端口提供，只提供小窗构建资源，不列目录，不连接业务后端或外部页面。

仓库查询通过原生桥接，以 SQLite `mode=ro` 只读打开 `youzi_v2/data/youzi_v2.db`，仅查询仓库编码、邮编及国家，不运行业务库初始化、迁移或写入。每次查询即时读取，地址簿更新后无需复制数据；无需后端进程。数据库文件或表缺失时不自动创建，窗口仍可核价，查询提示手动填写。浏览器预览没有此原生能力。

`youzi_v2/data/desktop_quote/preferences.json` 仅保存显示字段、置顶状态、汇率与字段布局版本标识。原生API按白名单接受设置，忽略客户、报价金额等额外数据；旧设置缺少汇率时使用默认值，非法汇率回退默认值。WebView使用私密模式，不持久保存本次报价。现有Git规则已忽略 `data/`、`.venv/` 和 `build/`。

## 验证

```powershell
node --test youzi_v2/tests/test_quote_widget.cjs
python -B -m unittest youzi_v2.tests.test_desktop_quote -q
```

合成数据覆盖识别、计费、附加费、非法输入和复制过滤；Windows实窗检查输入、置顶切换、字段开关与偏好保存。未读取真实客户数据或自动发送报价。


若启动提示找不到旧 Python 路径，说明虚拟环境引用的系统 Python 已移动或卸载。安装当前 Python 后重新运行安装脚本会检测并更新虚拟环境绑定；修复不会清理报价偏好。
