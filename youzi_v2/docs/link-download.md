# 链接批量下载

入口：工具中心 → 链接批量下载（`/tools/link-download`）。不要求运单已存在，不读取或修改运单业务字段。

## 输入

每行填写 `运单号 = 查看链接`，也支持空格、Tab、全角等号；兼容转义的协议冒号及行尾反斜杠。上方粘贴区实时解析到下方表格，表格支持修改、添加、删除。没有粘贴内容也可直接填表。手工修改后再改文本，需显式选择追加或替换，不会自动覆盖。重复运单号（不区分大小写）全部标错；只提交有效行，每批最多 100 行。

## 站点规则

第一版支持提货照片平台。规则定义于 `services/link_download.py` 的 `RULES`，限定协议、主机、端口和路径；查看路径 `/photo/image` 转成下载路径 `/photo/image/pack`，保留查询参数，需要非空 `id`。也接受已经转换的下载路径。链接不允许嵌入账户密码或片段；不跟随重定向，不把网页保存为 ZIP。扩展站点应新增受支持的匹配与转换规则，前端通过规则接口读取校验条件，无需复制站点配置；不接收任意下载目的地。

## 后台执行与文件

后端线程执行，刷新和切页不会中断任务；重启后端不会续传未完成文件，读取历史时标记中断，允许只重试失败项（创建新批次，保留原记录）。同时最多两个批次，每批最多并发三票，连接异常或超时重试一次。单票上限 50MB，每批网络流量上限 500MB（含重试），单票最长流式传输 180 秒。验证 ZIP 后以 `运单号.zip` 保存，内容不解压、不改写；汇总包只包含成功票的原 ZIP，支持部分成功及单票下载。

任务保存在 `link_download_jobs`，文件存于 `youzi_v2/data/link_downloads/<任务UUID>/`。下载有效期七天；新建任务时清理已过期的本工具 UUID 目录，保留数据库历史。运行中或被占用的文件跳过清理，下次再尝试。文件到期或丢失需重新下载。

## 任务与历史

新任务自动写入全局任务历史。后端管理状态不可被前端任务快照覆盖；顶部任务入口定时更新运行中任务，点击进入下载详情。页面提供最近 50 批历史，成功/失败票数、失败单号复制、只重试失败项和文件下载。后端重启后未结束的批次显示中断结果，不假装仍在执行。旧记录不会自动填进输入区覆盖本次编辑。

业务链接和单号只保存在本地数据库，下载文件为本地业务数据，不提交 Git，不写入更新记录；本工具不自动发送给其他人。

## API

- `GET /api/v1/tools/link-download/rules`：可用站点规则与路径，供前端校验及查看链接生成。
- `POST /api/v1/tools/link-download/jobs`：`{ rows: [{ shipmentNo, url }] }`，创建并立即返回任务。
- `GET /api/v1/tools/link-download/jobs`：最近 50 批任务。
- `GET /api/v1/tools/link-download/jobs/{id}`：当前状态、逐票结果、过期标记。
- `POST /api/v1/tools/link-download/jobs/{id}/retry`：为失败票创建新批次。
- `GET /api/v1/tools/link-download/jobs/{id}/download`：成功票汇总包；可传 `index` 下载指定成功票。

部署后需重启后端自动创建表，并刷新前端。首次真实下载需验证平台实际返回 ZIP；开发测试使用合成数据和模拟响应，不访问真实照片。


### 未完成文件清理

下载内容先写入 `.zip.part` 临时文件，完成并验证 ZIP 后原子改名为正式文件；失败及重试前尝试删除该次临时内容，不覆盖已有成功文件。删除失败时，后台记录警告，保留单票的下载结果，其他成功票仍会生成汇总包。因删除失败或进程被强制终止而残留的文件由七天过期清理处理。
