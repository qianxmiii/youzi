# 客户地址簿设计

**状态**：已确认  
**日期**：2026-11-02

## 目标

在客户中心单独管理客户自己的收货联系地址。一个客户可以有多条地址，不设默认地址。与资料中心的派送地址簿、仓库地址簿分开。

## 数据

新表 `customer_addresses`，建在现有本地库 `youzi_v2/data/youzi_v2.db`。该目录和 `*.db` 已在 `.gitignore` 中。提交的只有表结构、接口和页面。不写种子数据，文档和更新记录不放真实客户名、电话、邮箱或地址。

| 字段 | 说明 | 必填 |
|------|------|------|
| `id` | 主键 | 是 |
| `customer_name` | 客户名，必须能在客户管理中找到 | 是 |
| `label` | 地址简称。可以不填，库存空字符串 | 否 |
| `consignee_name` | 收货人名 | 否 |
| `company` | 收货人公司名 | 否 |
| `phone` | 收货人电话 | 否 |
| `email` | 收货人邮箱 | 否 |
| `country` | 国家 | 是 |
| `address` | 收件人地址，一整段，不拆州和城市 | 是 |
| `postcode` | 收件人邮编 | 否 |
| `address_kind` | 地址类型，三选一：`WAREHOUSE` 海外仓、`COMMERCIAL` 商业、`RESIDENTIAL` 住宅 | 是 |
| `is_remote` | 是否偏远。三种类型都可以标，默认否 | 否 |
| `note` | 备注 | 否 |
| `created_time` / `updated_time` | `YYYY-MM-DD HH:mm:ss` | 是 |

同一客户的地址简称可以重复，也可以为空。不设 `is_default`。简称为空时，列表标题依次用收货人名、公司名、地址开头代替。

保存时按去掉首尾空格后的客户名核对客户表，大小写不敏感。找不到客户则拒绝保存。客户管理里修改客户名并选择同步运单时，同时更新这些地址的客户名。该客户没有运单时，改名直接带上客户地址簿。删除客户不删除地址，地址仍按原客户名保留，与运单相同。

## 页面

客户中心增加「客户地址簿」，路由 `/customers/addresses`。不放进现有 `/addresses`。

列表可按客户、地址类型和是否偏远筛选，并可搜索地址简称、收货人、公司、电话、邮箱、地址、邮编和备注。每条显示类型和偏远。支持新增、修改、删除、复制，以及按当前筛选导出 Excel、下载模板、导入 Excel。可勾选多条，批量复制或批量删除。页面上客户名用下拉选择，不能手填一个客户管理里没有的名字。地址类型必选一项。偏远默认不勾。简称可以留空。

复制写入剪贴板，每项一行，只写内容、不写字段名。顺序为：收货人公司名、收货人名、收货人电话、收件人地址、收货人邮箱。某一项为空则省掉该行。邮编、国家、简称、备注和地址类型不进入复制文本。批量复制按列表当前顺序拼接，两条地址之间空一行。批量删除前需确认。

客户管理里点击客户名，打开该客户的地址列表，并带上客户筛选。

## 接口

前缀 `/api/v1/customer-addresses`。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 列表。`customer` 精确匹配客户名；`addressKind` 为 `WAREHOUSE`、`COMMERCIAL` 或 `RESIDENTIAL`；`remote` 为是否偏远；`search` 模糊匹配简称和各联系字段 |
| POST | `/` | 新建 |
| PUT | `/{id}` | 修改 |
| DELETE | `/{id}` | 删除一条 |
| POST | `/batch-delete` | 按 `ids` 批量删除。静态路径注册在 `/{id}` 之前 |
| GET | `/export` | 按当前筛选导出 Excel，表头与模板一致 |
| GET | `/template` | 下载导入模板。示例只用虚构数据 |
| POST | `/import` | 上传 Excel，只新增，不按简称更新已有记录 |

导入列：客户名、地址简称、收货人名、收货人公司名、收货人电话、收货人邮箱、国家、收件人地址、收件人邮编、地址类型、偏远、备注。地址类型接受「海外仓 / 商业 / 住宅」。偏远接受「是 / 否」，空着视为否。客户名、国家、收件人地址、地址类型必填；简称可空。客户名必须已存在于客户管理，否则该行失败并跳过。返回新增数、失败数和最多 50 条错误（含行号）。上传文件只作当次解析，不写入仓库。静态路径 `/export`、`/template`、`/import` 注册在 `/{id}` 之前。

## 非目标

- 不从 JSON 导入。Excel 只新增，不更新已有行。
- 复制只写入剪贴板，不把地址写入运单，也不在报价里自动带出。
- 不设默认地址。
- 不记录产品名或仓码。海外仓只是地址类型，不填写仓库编码。
- 不把真实地址写进仓库。
